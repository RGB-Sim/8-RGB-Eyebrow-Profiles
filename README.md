# 8-RGB-Eyebrow-Profiles
SimHub LED Profiles For 8 RGB Eyebrows

# Installation Instructions

1. Click the 'latest' Profile release on the right of this page and then select the '.ledsprofile' file from the list and choose a download location on your PC.
4. In SimHub select the 'Devices' tab and open your 8 RGB Eyebrows device settings.
5. In the 'Telemetry Leds effects' section, select 'Import Profile'. Navigate to your PC download location and select the '.ledsprofile' file.
6. Your new LED profile should now be loaded and '8 RGB Eyebrow - Default' should now be displayed in the 'Telemetry Leds effects' section.
7. Selecting 'Edit Profile' will allow you to switch the profile modes (only one should be switched on at a time) or edit the sections to your own liking.
